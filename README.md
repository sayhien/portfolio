# Loo Say Hien portfolio

Static site built with [Astro](https://astro.build).

```sh
npm install
npm run dev      # local preview at http://localhost:4321
npm run build    # production build in dist/
```

- Homepage projects and site details: `src/data/site.ts`
- Case study pages: `src/pages/*.astro`, images in `src/assets/`
- Shared case study layout with the section nav: `src/layouts/CaseStudy.astro`
